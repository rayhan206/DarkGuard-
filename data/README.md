# DarkGuard data

`text_dataset.csv` is generated by `training/download_text_data.py` from Yamanaka et al.'s public [EC dark-pattern dataset](https://github.com/yamanalab/ec-darkpattern). The script keeps the five text classes used by DarkGuard, strips empty rows, removes exact duplicate text, preserves `page_id`, and assigns train/validation/test splits by page rather than by row. The original TSV remains the source of truth.

`structural_examples.csv` is generated locally by `training/build_structural_data.py`. It is a **controlled synthetic dataset**, not a sample of real websites. Each `template_id` describes one fictional layout and has several numerical variations. All variations from one template stay in the same split. Its evaluation can show that the Random Forest learned the controlled examples; it cannot prove generalisation to real e-commerce sites.
